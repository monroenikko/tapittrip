# flutter-premium-ui

TapItTrip's Flutter UI skill. Agents read `SKILL.md` before any UI work in `client/`.

| File | Purpose |
| --- | --- |
| `SKILL.md` | Short rules: brand colors, tokens, states, workflow |
| `references/brand-colors.md` | Full palette, dark mode, contrast, copy-paste theme code |
| `references/design-review.md` | Review checklist |
| `references/example-prompt.md` | How to invoke the skill |
| `assets/tapittrip-logo.jpg` | Logo the colors were sampled from |

Keep one copy of this skill. Update colors in `brand-colors.md` and the app theme in the same change.
